音声入力のやり方（発音・スピーキングで使います）

このページはマイクを直接使えないので、端末の音声入力で話した英語を文字にして照合します。

Android（Gboard）：入力欄をタップ → キーボードのマイクで話す。Gboard に English (US) を追加し、地球儀キーで英語にしておく。

iPhone：設定 → 一般 → キーボード で「音声入力」をオンにし、英語キーボードで入力欄のマイクを押す。

Windows：入力欄をクリック → Win + H。

音素単位の厳密な判定は、PC の「発音コーチ（pron-coach）」を使ってください。
