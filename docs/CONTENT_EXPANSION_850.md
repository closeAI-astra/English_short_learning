## 学習順と到達確認

```text
診断：初見の時間制限演習 → 誤因を分類
├─ 1 文の骨格：品詞・一致・時制・態・修飾
├─ 2 音の理解：目的・担当・条件・変更・意図
├─ 3 文脈の理解：接続・言い換え・推論・複数文書
└─ 4 転用：会話・生活題材 → 自分の例で説明
    └─ 数日後に原文なしで再現 → 別の初見教材で確認
```

ホームの「教材」を選ぶと学習コースの4段階の順序と確認基準を表示。ホームの初期表示と「ショート」ではコース説明を出さず、動画の一覧を表示する。「テーマ別に選ぶ」から会話3シリーズと題材別一覧へ進める。既存長文38本も一覧から開ける。苦手な段階から始め、既習項目は確認問題と理由説明で点検して先へ進んでよい。

1日の一例はショート2〜4本、長文1本、誤答の根拠確認、以前の表現を原文なしで再現。新作だけでも複数週に分けて取り組める分量だが、必要日数や得点上昇は保証しない。週ごとに別の初見素材で同じ技能が使えるか確認する。

## 表現の編集基準

- I understand、I'm fine、Let's eat together、My hobby is、I have a question、I want to eat something を一律に誤りとしない。
- Got it は指示の受領、I see は理解の変化、That makes sense は理由への納得という役割を例で比較。
- What do you mean by that? は自動的に柔らかくならない。対象を具体化し、調子・状況も扱う。
- toilet と bathroom/restroom の地域差を区別。米語の推奨を世界共通ルールにしない。
- bored/boring は感じる側・原因側で整理。人なら常に -ed という誤った規則を作らない。
- 教科書表現であること自体を、不自然さや非使用の根拠にしない。
- ネイティブへの取材・実測の使用頻度を装わない。対話・登場人物・店・取引例は創作。

## 編集・再現・検査

編集元：`materials/_native.txt`、`_curiosity.txt`、`_bridge850.txt`、`_bridge_readings.txt`。各ブロックの英日をタブで区切る。ショート末尾は語彙、問題、解説。長文は6段落と4問。編集元の正解選択肢を先頭に置き、生成時に正解位置を分散する。

```powershell
python -X utf8 materials/_build_expansion.py
python -X utf8 materials/validate.py
python -X utf8 build_site.py
node test_video.cjs
node test_art.cjs
node test_study.cjs
node test_fluency.cjs
node test_coverage.cjs
.\.venv\Scripts\python.exe -X utf8 -m unittest test_learning -v
```

生成先は `shorts_native.json`、`shorts_curiosity.json`、`shorts_bridge850.json`、`stories_bridge850.json`。学習経路は `curriculum.py`。経路に存在しないIDがあるとビルドを止める。教材ID・既存フレーズIDを維持し、既存の復習記録をリセットしない。

検証では新作数、全124本の経路到達性、ID重複、字幕対応、語数、語彙、選択肢、解説の書き出し、回答前に解説を出さないこと、回答後に該当解説だけを出すことを確認。既存の再生・設問・復習・4/3/2・発音コーチのテストも実行。発音テストには専用 `.venv` を使う（汎用Pythonには phonemizer がない場合がある）。

語彙リストの表層カバー率は、全教材で NGSL 68.8%、TSL 65.9%、合算67.9%。読み聞きに現れる範囲では合算63.9%。これはリスト掲載語の出現確認で、習得率・TOEICカバー率・予測スコアではない。850に必要な語彙を有限の語彙リストだけで完全保証することもできない。

画面の自動確認は、この実行環境のブラウザー接続がタイムアウトしたため未完了。プレーヤー・経路・解説の動作はプログラムの回帰テストで確認。読み上げ音声の実聴、実機スマートフォンの表示、公開URLへの反映は別途確認が必要。

ローカル本体 `english-express.html`、公開用 `docs/index.html`、公開用ZIPを更新。Gitへのコミット・プッシュや公開URLの更新は今回実行していない。


## 動画イラストの追加

題材に対応するSVGイラストを30種類（ボトル、キャップ、服、信号、エレベーター、値札、レシート、ポップコーン、搭乗券など）、背景を5種類（街路、店舗、ホテル、台所、リサイクル）追加。外部画像の取得なしでオフライン表示できる。

追加110本のショートの440場面は `scene_content.py` に場面ごとの組み合わせを指定し、各動画で3種類以上の異なる場面を表示する。長文・フレーズ動画は `video-app.js` の字幕キーワードから新しい絵を優先して選ぶ。図形は `art-topic.js`、利用可能な名前は `materials/validate.py`、埋め込みは `build_site.py` で管理する。

`node test_art.cjs` で全場面の背景・図形の存在、描画への含有、場面の変化、字幕からの選択を確認する。`--preview` を付けると `output/video-art-preview.svg` を生成する。今回のPNG一覧はSVGから描画して目視確認した。ホーム初期表示からコース説明を外し、教材タブに説明と経路を残した。
