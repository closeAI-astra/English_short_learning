# English Express

ブラウザーだけで動く英語学習アプリです。1つの `index.html` にすべて入っていて、サーバー・APIキー・ビルド環境は不要です。

- ホーム：動画形式の教材（長文リスニング・リーディング、フレーズセット、想起、聞き分け、4/3/2 スピーキング）。教材ごとに設問・塊・速読・速聴・スクリプト・発音チェックへ切り替えられます
- ショート：英語ナレーションの紙芝居ショートが連続再生され、間にフィードの練習問題が混ざります。右のボタンか左スワイプで、その教材の詳しい学習へ
- マイページ：間違えた項目の一覧と、練習・教材を自分で選ぶ入口
- 動画ページ：YouTube に近い操作（場面ごとのチャプター付きシークバー、字幕 CC、再生速度、シアターモード・全画面、概要欄のチャプター、次の動画の一覧と自動再生）。キーボード操作：K/スペース＝再生・停止、J/L＝前後の場面、C＝字幕、T＝シアター、F＝全画面。時間は1倍速・約150語/分の目安です
- 音素チェック（ホームの「音素」）：一般米語の40音それぞれに、口の断面図または母音図、日本語話者のつまずき、お手本、単語チェック、録音比較、聞き分けテスト、発音コーチへの受け渡し。単語チェックはブラウザーの音声認識（Chrome・Edge・Safari）を使い、「どの単語に聞こえたか」だけを判定します。音素ごとの採点は Python の発音コーチで行います。録音は端末内で再生するだけで保存・送信しません
- 600点台→850向けの学習コース：新作ショート110本・長文14本・解説付き確認問題166問を追加。既存分を合わせて独立ショート238本・長文52本です（長文の分割再掲・場面練習・フレーズ動画は別枠）。Native or Weird? の3シリーズ、生活題材50本、Part 1〜7のスキル別練習をホームから選べます。既存のTOEIC向け長文・語彙も利用できます。視聴本数・正答率はスコア保証ではありません。`node coverage.cjs` で NGSL+TSL の語彙カバー率を計算できます（公開前の自動テストで50％超を確認）

## GitHub Pages で公開する

どちらか一方で公開できます。

**A. 公開用ファイルだけを置く（簡単）**
`english-express-github-pages.zip` を展開し、中身（`index.html` `.nojekyll` `README.md` `HVPT_PACK.md`）を新しいリポジトリの直下に置きます。Settings → Pages → Deploy from a branch → `main` / `(root)` → Save。

**B. 作業フォルダーごと置く（教材を追加しながら更新する）**
pron-coach フォルダーをリポジトリにし、Settings → Pages → Deploy from a branch → `main` / `/docs` → Save。`build_site.py` が `docs/` を毎回作り直します。教材を追加したら `publish.bat` をダブルクリックするだけで、チェック・ビルド・アップロードまで行われ、公開ページが更新されます。`.gitignore` により、`results.csv`・録音・`.venv`・`.env` はアップロードされません。

無料プランの GitHub Pages は公開リポジトリが前提です。ページの中身（教材）は誰でも見られますが、学習記録は各自のブラウザーにだけ保存され、GitHub には送られません。

## データと対応環境

- 学習記録は同じ端末・同じブラウザーの中（localStorage）に保存します。端末間の自動同期はありません。ブラウザーのデータを消すと失われます
- 外部への通信は Google Fonts の読み込みと、ユーザーが押したリンク（YouTube・発音コーチ）だけです。取得できない場合はシステムフォントを使います
- 読み上げはブラウザー・OS の音声を使います。録音はHTTPSとマイク許可が必要です
- 音素評価用の Python 発音コーチは別アプリで、GitHub Pages 上では動きません。マイページの設定で、自分が使える発音コーチの URL を指定してください
- Claude 上で開いたときだけ使える機能（AI による教材生成など）は、GitHub Pages 版では表示されないか、使えません

## 教材の追加

`materials/` に JSON を置いて `publish.bat` を実行します。詳しくは `materials/README.md`。ほかの AI に教材を作ってもらうときは `AI_CONTENT_GUIDE.md` を貼ってください。
